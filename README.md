# CogniVox
CogniVox is a full-stack AI web application that bridges the gap between visual content and audio accessibility. It uses Azure Computer Vision to perform high-accuracy OCR on uploaded images — handling PNG, JPG, WEBP, BMP, and TIFF . Tech Stack: Python · Streamlit · Azure Computer Vision API v3.2 · Azure Neural TTS REST API · Pillow · Formspree
